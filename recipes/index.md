# The NMCA-DT Cookbook recipes

The academic **NMCA-DT Framework** provides the conceptual architecture — which
contextual, analytical and action-oriented modules matter when a National Mapping
and Cadastral Agency (NMCA) assesses its role in Digital Twins (DTs). This
cookbook operationalises that architecture into ten **modular recipes** that an
NMCA selects according to the decision it needs to make.

> The framework defines the analytical architecture; the cookbook provides the
> operational recipes; the templates are the evidence-gathering instruments that
> let NMCAs move between the two.

This is **not a single linear method**. Treat the recipes as a menu. Each recipe
answers a different question and produces a concrete output that later recipes
can reuse.

## How to choose where to start

1. **Name your decision need.** What decision will this work support?
2. **Find the matching situation** in the [workflow pathways](workflow-pathways.md)
   and follow the suggested recipe sequence.
3. **Run only the recipes you need.** An NMCA assessing an initial opportunity may
   need only Recipes 1–2; one seeking strategic investment may need Recipes 2–9;
   one advising government may need Recipes 4–9.
4. **Carry outputs forward.** Each recipe's output is an input to the next, so the
   sequence matters more than completeness.

## Common recipe format

Every recipe follows the same culinary-metaphor structure so that users can read
it quickly:

- **Decision question** — the practical question the recipe answers.
- **Goal** and **When to use this recipe**.
- **Framework modules operationalised** — the link back to the academic framework.
- **Ingredients / required inputs** — evidence, people, documents, data and templates.
- **Method / step-by-step process**.
- **Templates / tools used** — the chef's toolkit.
- **Outputs / plating up** — how to present the result and what to do next.
- **Quality checks and evidence notes** — evidence strength, assumptions and uncertainty.
- **Suggested next recipes**.
