# Recipe 6 — Map PSGI value pathways

> **Decision question:** What value could NMCA contribution create, for whom and through what mechanism?

## Goal

Explain how NMCA contribution creates value in a Digital Twin context, for whom
and through which mechanisms. The aim is to move beyond vague benefit claims and
make the public value argument explicit. (PSGI = public sector geospatial information.)

## When to use this recipe

- When selecting pilot use cases and needing a value rationale.
- When building an investment case or advising on national strategy.
- Whenever benefit claims need to be made measurable and defensible.

## Framework modules operationalised

- Value pathways
- Public value

## Ingredients / required inputs

- Preferred role (from Recipe 5)
- Stakeholder map and PSGI assets
- Value enablers from the PhD value paper (Metcalfe et al., 2026)
- Public policy objectives and benefit evidence
- Existing evaluation indicators

## Method / step-by-step process

1. Identify beneficiaries and affected groups.
2. Map PSGI value enablers such as accuracy, trust, quality, fitness-for-purpose,
   interoperability, public good characteristics, network effects and spillovers.
3. Connect enablers to value dimensions: economic, functional, societal,
   environmental and knowledge-based value.
4. State assumptions behind each value pathway.
5. Define measurable or observable indicators.
6. Identify what value would be lost if the NMCA did not contribute.

## Templates / tools used

- Value pathway canvas
- Stakeholder and beneficiary map
- Risk, assumption and uncertainty register

## Outputs / plating up

- Value pathway map
- Beneficiary table
- Assumptions register
- Public value narrative
- Draft indicators for later monitoring

The draft indicators are reused in Recipe 10 to monitor whether value was realised.

## Quality checks and evidence notes

- Each value pathway has stated assumptions and at least one indicator.
- The counterfactual ("value lost if NMCA does not contribute") is articulated.
- Indicators are observable or measurable, not rhetorical.
