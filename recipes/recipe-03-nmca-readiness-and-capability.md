# Recipe 3 — Assess NMCA readiness and capability

> **Decision question:** Are we ready to contribute, and what capabilities do we already have?

## Goal

Establish whether the NMCA has the organisational, technical and relational
capabilities needed to support Digital Twin engagement. This recipe creates a
capability baseline that later recipes can compare against use-case requirements.

## When to use this recipe

- When deciding whether the agency can credibly engage with a DT case.
- When establishing a reusable capability baseline across multiple cases.
- Before any investment case or gap diagnosis.

## Framework modules operationalised

- NMCA profile
- Capability baseline

## Ingredients / required inputs

- Existing readiness assessment and data catalogues
- Update cycles and QA processes
- API documentation, cloud and architecture documents
- Skills profile and partnership agreements
- User feedback and innovation strategy

## Method / step-by-step process

1. Define the assessment scope: whole agency, department, data portfolio or specific use case.
2. Assemble a cross-functional assessment group.
3. Score capabilities across data foundation, technical infrastructure and advanced capabilities.
4. Gather evidence for each score, avoiding unsupported self-assessment.
5. Identify strengths, weak spots and capability dependencies.
6. Interpret whether the agency is ready to **lead, support, advise, partner or defer**.

## Templates / tools used

- NMCA readiness and capability assessment
- DT-Geospatial Complexity Index scoring sheet (for comparison)

## Outputs / plating up

- NMCA readiness profile
- Capability baseline
- Evidence notes
- Strengths and weaknesses summary
- Initial capability gap list

Reuse the capability baseline across use cases and feed it into role configuration and gap diagnosis.

## Quality checks and evidence notes

- Every score is supported by documented evidence, not self-assessment alone.
- The assessment scope is explicit and consistent.
- Capability dependencies and single points of failure are recorded.
